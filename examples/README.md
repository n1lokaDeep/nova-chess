# Примеры

Запускать из корня репозитория. Каждый скрипт сам добавляет корень
в пути импорта, так что можно и из папки `examples`.

## Нужна модель

Все примеры, кроме разбора Stockfish-части, требуют веса Nova.
Скачайте их по инструкции из основного [README](../README.md):

```
models/nova_v3b.onnx
models/nova_v3b.onnx.data
```

Stockfish не обязателен — без него скрипты работают, просто без оценки ходов.
Путь можно задать переменной окружения:

```bash
export NOVA_STOCKFISH_PATH=/path/to/stockfish
```

## Разбор позиции

Что сыграли бы люди заданного рейтинга:

```bash
python examples/analyze_position.py --rating 1500
python examples/analyze_position.py --rating 2400 --top 8
python examples/analyze_position.py --fen "8/8/8/3q4/8/8/8/3RK2k w - - 0 1"
```

Вывод — список ходов с долей людей, которые так играют, и (если подключён
Stockfish) оценкой каждого хода.

## Партия против движка

Игра в терминале. Ходы вводятся как UCI (`e2e4`) или SAN (`e4`, `Nf3`):

```bash
python examples/play_game.py --rating 1600
python examples/play_game.py --rating 1200 --color black
```

Слабее рейтинг — чаще встречаются человеческие ошибки: на 800 проходят
зевки, которые на 2400 отсеиваются фильтром.

## Сравнение движков

Наглядно показывает разницу между Nova и Maia-2:

```bash
python examples/compare_engines.py
python examples/compare_engines.py --fen "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1"
```

Maia-2 необязательна: если пакет не установлен, сравнение идёт только
по Nova, и об этом сообщается в выводе.

## Что важно помнить

- **Доля — это частота выбора людьми, а не сила хода.** Ход с 60% может
  быть объективно плохим — просто его часто играют.
- **Nova слабо реагирует на рейтинг.** Причина и подробности — в
  разделе предупреждений основного README.
- **Maia-2 работает медленнее** — 2–4 секунды на ход.
