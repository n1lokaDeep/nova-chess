# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [1.0.0] — 2026-10-11

Первый публичный выпуск.

### Добавлено

**Ядро**

- Кодирование позиции в тензор `(18, 8, 8)` для модели Nova
- Обёртка над ONNX-моделью: распределение вероятностей по всем легальным ходам
- Фильтр качества через Stockfish с отсевом ходов по допустимой потере
- Калибровка по рейтингу: порог фильтра выводится из уровня игрока
- Обёртка над Maia-2 с учётом рейтинга обоих игроков
- Оценка ожидаемого результата партии по Maia-2

**Интерфейсы**

- CLI с командами `moves`, `play`, `compare`, `selfplay`
- Веб-сервер с доской в браузере
- Выбор движка в адресе: `#nova`, `#maia`, `#sf`

**Веб-интерфейс**

- Три движка с отдельной панелью настроек у каждого
- Стрелки подсказок на доске, от 1 до 5, толщина зависит от вероятности
- График оценки партии по полуходам с пересчётом линии
- Плавная анимация фигур: сопоставление между позициями, переезд вместо телепорта
- Подсветка шаха и доступных ходов
- Загрузка позиции по FEN, копирование текущей, вставка из буфера
- Полоса оценки, всегда с точки зрения белых

**Качество**

- 62 теста: кодирование, индексация ходов, движки, фильтр, гибрид, перспектива
- CI на GitHub Actions: Python 3.10–3.12 на Linux, отдельно Windows
- Отчёт покрытия в сводке запуска

**Документация**

- README с предупреждениями об ограничениях каждого движка
- Три примера запуска в папке `examples/`
- Описание API сервера

### Известные ограничения

- Nova в открытом релизе без калибровочного слоя: разница между
  рейтингами выражена слабо, для имитации уровня Maia-2 подходит лучше
- Maia-2 работает заметно медленнее: 2–4 секунды на ход
- Maia-2 обучена только на диапазоне 1100–1900
- Nova и Maia-2 не считают варианты: это policy-сети без поиска
- Оценка позиции требует Stockfish
- В CI тесты, зависящие от модели и Stockfish, пропускаются
